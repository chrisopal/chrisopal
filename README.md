# chrisopal

## 每日10词背诵计划

`public/` 目录中包含一个可以直接部署的前端应用，帮助学习者每天背诵 10 个主题词汇。

### 功能一览

- 按天查看学习计划，每天 10 个精选单词。
- 每个单词包含音标、中文释义、英文例句、中文翻译与配图。
- 点击「🔊 发音」可调用浏览器语音朗读单词与例句。
- 支持标记已掌握单词并记录学习时长（本地存储）。
- 内置当日测验，自动生成四选一的释义选择题并统计正确率。

### 本地预览

```bash
cd public
python3 -m http.server 1313
```

随后访问 <http://localhost:1313> 即可体验。
